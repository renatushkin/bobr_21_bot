Тема: Git в Школе 21

Git — система контроля версий, которая помогает
сохранять изменения в проекте.

git status — показывает состояние рабочего дерева.
git add — добавляет изменения в индекс.
git commit — сохраняет подготовленные изменения.
git log — показывает историю коммитов.
git push — отправляет коммиты в удалённый репозиторий.

Если возникла ошибка, сначала проверь git status
и внимательно прочитай сообщение терминала.

Это демонстрационный учебный материал,
а не официальная инструкция Школы 21.
